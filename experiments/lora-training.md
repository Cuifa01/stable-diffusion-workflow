# Myon_style LoRA Training — Dataset Curation

**Status:** Dataset audit complete and first SDXL LoRA training configuration selected (updated 2026-10-15). **No completed personal LoRA or verified training run is documented yet.**  
**Experiment:** A personal SDXL / Illustrious-oriented **Myon_style** *style LoRA*, intended to reproduce the character rendering of the finished NeoForge images.

## Scope and Model Distinction

**Myon_style** describes the author's preferred aesthetic: expressive anime faces, clean line art, glossy hair highlights, controlled cel shading, soft skin rendering, and relatively simple backgrounds. The immediate goal is **character/style transfer across different characters, outfits, expressions, and camera angles**, rather than memorizing one character or a particular pose.

The existing results come from **WAI-Illustrious v15 + artist-style prompt tags + an external `nyalia` LoRA (weight `0.6`) + Hires.fix + face-only ADetailer**, as documented in [the signature preset](../style/signature-style.txt). **They are not generated by a finished Myon_style LoRA.** A personal LoRA has not yet been evaluated or released.

### 1.2 角色清单（11 人）

| 作品 | 角色 |
| --- | --- |
| 东方 Project | 魂魄妖梦、四季映姬、雾雨魔理沙、古明地觉、古明地恋、琪露诺、蕾米莉亚、芙兰朵露 |
| Blue Archive | 鬼方佳代子、阿罗娜、天童爱丽丝 |

计划为**每位角色准备 5 个不同的构图/表情/动作模板**，每个模板连续生成 3 张候选，分别筛图；**不要求每个模板机械保留三张**。注意均衡角色、发色、面部角度、表情及服饰，避免让画风 LoRA 绑定某个角色的固定造型。

### 1.3 每位角色的五种构图类型

| 模板 | 构图方向 | 主要学习目标 |
| --- | --- | --- |
| A | 正面脸部特写：`portrait, close-up, from front` | 五官、眼睛、腮红、脸型与 ADetailer 后的面部质感 |
| B | 3/4 视角脸部/胸像 | 侧向脸型、发束、高光、眼睛透视 |
| C | 上半身 + 一个简单动作 | 手与面部相对位置、服装局部细节 |
| D | 腰部/大腿以上构图：`upper body` / `cowboy shot` 按画面选 | 身形轮廓、服装褶皱与上色 |
| E | 轻动态 / 轻透视 | 适应不同视角，不只学习正面肖像 |

这些是**采样覆盖维度**，不是要求每张通过筛选。表情可覆盖 `smile`、`wink`、`open mouth`、`serious` 等；动作以轻量、结构清晰为主。背景总体偏简单，但可以使用白色、粉色、浅色块或少量轻场景，不要强行统一成纯白。

### 1.4 与当前生成工作流的关系

- 保持已有的六段 `BREAK` 正向 Prompt 结构，以及 [signature-style.txt](../style/signature-style.txt) 中的固定画风预设；各模板更改角色、视角、表情、动作、服装。
- 使用作者已经配置好的 **Hires.fix** 与 **face-only ADetailer** 获取最终风格。此次批量任务在 ADetailer **Negative Prompt** 中另追加 `sweat,`；这属于生成配置，不是训练 Caption。
- 训练图使用**经过全部后处理的最终成品**；保留原图宽高比。首轮可考虑 SDXL 1024 尺度的 resolution bucketing，但**训练参数尚未定稿**。
- 生成所用的 artist tags / 外部 LoRA 是**素材来源的一部分**，不是独立训练完成的 Myon_style LoRA。正式训练后的效果必须与现有组合工作流分开验证。

## 2. Curation & Quality Control / 筛图标准

此前先从候选中初选了 43 项；之后本地数据集审计确认了 45 对有效图文文件。质量检查遵循以下标准：

1. **符合目标画风：** 脸部比例、虹膜高光、头发分组、线条、肤色、服装明暗接近目标成品。
2. **角色特征正确：** 发色、饰品、服装和重要识别特征没有被其他角色污染。
3. **局部结构合理：** 排除严重的多指、缺指、手部扭曲、五官错位、连接关系错误；重点检查脸部、手部和衣服图案乱码。
4. **样本非重复：** 同一模板的 3 张只保留有不同信息、且各自质量足够的图；不要用几乎相同的三张来凑数量。
5. **跨角色与构图覆盖：** 清点每个角色及 A–E 构图的入选量，优先补缺少的角度/表情/服装，而不是单纯补到某个总数。
6. **内容合规与来源留档：** 本轮训练图全部为 SFW；登记原始 Prompt、Seed、所用模型/LoRA 和后处理信息，并记录外部模型或素材的使用许可条件。

**门槛：** 不必强行凑齐 60 张；如果 43 个候选经清点后仍质量良好且覆盖充分，可以先做一次小规模 Style LoRA 验证，再根据测试结果补图。

## 3. Dataset Files & Captions / 文件与标注

建议本地整理（**此目录树是建议，不代表 GitHub 已上传这些图**）：

```text
myon-style-lora/
├── candidates/          # 已筛选候选；暂不视为正式训练集
├── train/
│   ├── 0001.png
│   ├── 0001.txt
│   ├── 0002.png
│   └── 0002.txt
├── holdout/             # 可选：留出的评估素材；不能和训练图近乎重复
├── metadata.csv         # 角色、模板 ID、Seed、原图路径、通过/剔除理由
└── evaluations/         # 固定 Prompt / Seed 的横向对比
```

**Caption 规则：**

- 每图一个同名 `.txt`，优先使用准确的 **Danbooru-style tags**，按作者习惯以空格书写；**逐图核对**角色、外观、服饰、镜头、动作、表情、背景。
- 本轮 WD14 的 `additional_tags` 设为 **`Myonstyle`**（大小写保持一致），用于在每张标注中加入候选风格触发词；训练前仍需核查标签，**不能将触发词写成已经训练成功的特性**。
- 背景标签与实际内容一致：粉色背景写 `pink background`，不能只因为想学角色画风就误标成 `white background`。
- `BREAK`、`<lora:...>` 和生成用的完整画师串属于**出图 Prompt/元数据**，一般不要机械复制到所有训练 Caption；Caption 重点描述可变的画面内容。
- 若从一个生成模板得到近似图，训练/留出评估时按模板分组处理，避免高度相似的图同时落入两边造成虚假的泛化结论。
- 不将整套 Hires.fix + ADetailer 流程视为“可由 LoRA 100% 替代”；实际替代程度必须用生成对比来判断。

### WD14 automatic tagging decision (2026-10-15)

Use the **SD-Trainer WD14 Tagger** for the **first-pass** image-to-Danbooru-caption extraction. The settings below are the selected tagging configuration; the generated captions still require manual review.

| Setting | Chosen value |
| --- | --- |
| `interrogator_model` | `wd-vit-v3` |
| `threshold` | **`0.5`** (confidence threshold for including predicted tags; this is a WD14 tagger setting, **not a diffusion sampler setting**) |
| `additional_tags` | **`Myonstyle`** (exact capitalization; append to every generated caption) |
| `replace_underscore` | **On** (replace tag underscores with spaces) |
| `escape_tag` | **On** (escape parentheses in tags) |
| `batch_input_recursive` | **Off** |
| `batch_output_action_on_conflict` | `copy` (preserve existing captions instead of overwriting them) |

**Procedure:** Run WD14 on the selected SFW candidate images. Inspect the same-named `.txt` files for character IDs, clothing, expression, pose, camera angle, and background. Manually remove incorrect tags and supply omitted character-specific tags. The proposed style trigger is **`Myonstyle`**, appended by this WD14 configuration. Verify it occurs once per caption and decide whether to keep it at training time; labeling and training have not yet been confirmed complete. The threshold of `0.5` is a selected initial configuration, **not** a measured optimal value or evidence that labeling has already completed.

## 4. Initial Training Setup (selected, not yet run)

**Versioned configuration snapshot:** [`configs/myonstyle-v1-initial.toml`](../configs/myonstyle-v1-initial.toml).

This TOML preserves the **first selected SD-Trainer values** supplied on 2026-10-15. It is a planning/configuration snapshot and **not** an exported training log or evidence of a successful run. The checkpoint and dataset-location fields are placeholders to be supplied when running locally. Parameters absent from the supplied configuration (such as `vae_batch_size`, `caption_dropout_rate`, or `clip_skip`) are **not silently added**.

**Confirmed dataset audit:** 45 images, 45 nonempty paired captions, zero missing/orphan/empty files, repetition folder prefix **5**. With `train_batch_size=1`, `gradient_accumulation_steps=1`, and `max_train_epochs=5`, the theoretical step count is **45 × 5 × 5 = 1,125**. Actual steps and training success are to be confirmed from trainer logs.

**Core selected choices:** Standard `networks.lora`; SDXL / WAI-Illustrious v15; resolution `1024,1024` with buckets; UNet-only; network dim 32, alpha 16; UNet LR `1e-4`, AdamW8bit, cosine scheduler; BF16 mixed precision; xFormers; gradient checkpointing and latent/text-encoder-output caches enabled; FP16 safetensors saved every epoch. Do not treat these as performance-validated hyperparameters.
